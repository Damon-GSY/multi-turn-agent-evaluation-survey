# Contributing

Corrections and resource suggestions are welcome through GitHub issues and pull requests.

For a resource suggestion, include the title, primary source URL, relevant evaluation category, and a brief explanation of its relevance to multi-turn conversational agents. For a correction, identify the affected entry and provide a supporting source.

Keep the arXiv v2 reference index and benchmark tables faithful to the paper. Clearly label resources published after that version. Preserve source attribution and respect the license of contributed material.
